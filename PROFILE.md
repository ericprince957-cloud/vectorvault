# VectorVault Developer Profiles

## Purpose
Every developer on VectorVault should have a public profile where people can discover their work, skills, and repositories.

## Profile Information

Each developer profile should support:

- Unique username
- Display name
- Profile picture or avatar
- Short biography
- Location (optional)
- Skills and technologies
- Personal website (optional)
- GitHub profile link (optional)
- Date joined

## Public Profile Page

Each developer should have a public profile URL:

`vectorvault.com/username`

Visitors should be able to view public profiles without creating an account.

## Profile Features

- View developer information.
- Browse the developer's public repositories.
- See repository descriptions.
- See the developer's listed skills.
- Copy the profile URL.
- Follow developers (future feature).

## Profile Editing

Authenticated users can:

- Update their display name.
- Change their avatar.
- Edit their biography.
- Add or remove skills.
- Update their website and location.

Users can only edit their own profiles.

## Privacy and Security

- Private account information must never appear publicly.
- Email addresses must not be exposed on public profiles.
- Users must not be able to edit another developer's profile.
- Public profiles should display only information intended for public viewing.

## Design Requirements

- Minimalist black and white interface.
- Gold accents for subtle highlights.
- Preserve the existing VectorVault logo.
- Responsive on mobile and desktop.
- Clean repository cards and readable typography.
