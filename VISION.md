# VectorVault — Our Vision

## What is VectorVault?

VectorVault is a minimalist code-hosting platform designed to make storing, managing and sharing code easier for Nigerian developers.

Built by Vector Codes.

## Our Mission

To make code hosting accessible to student developers, freelancers and the wider African developer community.

## Our Initial Focus

VectorVault will initially focus on two core experiences:

### 1. Developer Accounts
- Simple registration and login.
- Secure authentication.
- Personal account management.

### 2. Developer Profiles
- Custom usernames.
- Profile pictures.
- Personal biographies.
- Skills and technologies.
- Public repository listings.

## Our Philosophy

- Simplicity over complexity.
- Accessibility for everyone.
- Security and privacy.
- Clean and intuitive design.
- Continuous improvement.

## Our Long-Term Vision

Build a developer ecosystem where people can:

- Host their code.
- Manage repositories.
- Collaborate on projects.
- Discover developers.
- Showcase their skills.
- Find opportunities.
