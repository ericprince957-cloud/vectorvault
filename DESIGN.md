# VectorVault — Design System

## Brand Identity

Name: VectorVault

Tagline: Minimalist code hosting for Nigerian devs.

Founder: Prince Eric

Parent Brand: Vector Codes

## Official Logo

VectorVault uses its existing geometric V symbol.

The logo combines:
- White
- Blue

The original logo design must remain consistent across the platform.

Do not introduce alternative logo designs without a deliberate brand update.

## Colour Palette

### Interface

- Primary Background: #090909
- Secondary Background: #141414
- Primary Text: #FFFFFF
- Secondary Text: #A1A1AA

### Accent Colours

- Gold: #C9A227
- Light Gold: #E5C76B

### Logo Colours

- White: #FFFFFF
- Blue: Existing brand blue.

## Design Philosophy

VectorVault should feel:

- Minimalist
- Premium
- Professional
- Modern
- Developer-friendly

## Typography

Use clean, modern sans-serif typography.

Prioritize readability and consistency.

## UI Components

### Buttons
- Simple labels.
- Subtle rounded corners.
- Gold outlines for selected actions.
- Clear hover states.

### Cards
- Dark backgrounds.
- Subtle borders.
- Consistent spacing.

### Navigation
- Minimal navigation.
- Clear active states.
- Responsive mobile layout.

## User Experience

- Mobile-first design.
- Simple navigation.
- Fast loading.
- Accessible controls.
- Consistent spacing.

## Design Principle

Premium doesn't mean complicated.

Keep everything simple, purposeful and recognizable.
