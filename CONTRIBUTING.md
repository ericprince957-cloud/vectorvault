# Contributing to VectorVault

Thank you for your interest in contributing to VectorVault!

VectorVault is an evolving code-hosting platform built to make development more accessible to Nigerian developers and the wider African tech community.

## Our Principles

- Keep things simple.
- Write clean, maintainable code.
- Prioritize security.
- Respect other contributors.
- Build features that solve real problems.

## How to Contribute

1. Fork the repository.
2. Clone your fork.
3. Create a new branch.
4. Make your changes.
5. Test your changes.
6. Submit a pull request.

## Contribution Guidelines

- Use clear commit messages.
- Keep pull requests focused.
- Document significant changes.
- Avoid introducing unnecessary dependencies.
- Never commit API keys or secrets.

## Reporting Issues

If you discover a bug or have a feature suggestion, open a GitHub Issue with a clear description.

## Code of Conduct

Be respectful, constructive and welcoming to everyone.
